Быстрый локальный запуск 
git clone https://github.com/PushDocs/PushDocs.git
cd PushDocs
export PUSHDOCS_SESSION_PEPPER="$(openssl rand -hex 32)"
export PUSHDOCS_ENCRYPTION_KEY="$(openssl rand -base64 32)"
docker compose up --build
После запуска откройте localhost:8080 ↗

Для локального знакомства нужны Docker и Git. Настройки для сервера описаны в инструкции.

Для каких проектов подходит PushDocs?+

Для документации на Docusaurus, исходники которой хранятся в GitHub или GitLab. PushDocs работает с Markdown и MDX. В одной установке можно подключить несколько проектов с отдельными участниками и ролями.

Где хранятся мои документы?+

Исходники остаются в вашем Git-репозитории. Черновики, комментарии и загруженные до отправки файлы хранятся на сервере PushDocs. Изменения попадают в Git, когда редактор явно отправляет их.

Нужно ли редактору пользоваться терминалом?+

Для повседневной работы терминал не нужен. Можно редактировать исходный Markdown или MDX, добавлять файлы, сравнивать версии и создавать PR или MR в браузере. Первичную установку и подключения настраивает администратор.

Можно ли увидеть сайт до отправки в Git?+

Быстрый предпросмотр показывает Markdown без выполнения MDX-компонентов. Экспериментальный изолированный preview runner может собрать настоящий Docusaurus-сайт с черновиками. Администратор включает и настраивает его отдельно.

Что уже работает, а что ещё в разработке?+

В MVP доступны редактор, черновики, медиафайлы, комментарии, сравнение версий и отправка PR или MR. Слияние выполняется в GitHub или GitLab. Совместного посимвольного редактирования нет. Актуальные ограничения перечислены в README проекта.
